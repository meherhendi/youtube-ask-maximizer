How it works

Finding the panel

YouTube renders its side panels as ytd-engagement-panel-section-list-renderer elements. The Ask panel is identified by target-id="PAyouchat". YouTube mixes light DOM with open shadow roots, so the lookup recurses through both.

function deepQueryAll(selector, root, out) {
  root.querySelectorAll(selector).forEach(el => out.push(el));
  root.querySelectorAll('*').forEach(el => {
    if (el.shadowRoot) deepQueryAll(selector, el.shadowRoot, out);
  });
  return out;
}

Placing the button

The button is inserted immediately before #visibility-button (YouTube's close control) inside ytd-engagement-panel-title-header-renderer. If that structure isn't found, it falls back to the header container, then to absolute positioning over the panel.

Staying attached

YouTube is a single-page app that tears the panel down on navigation. A MutationObserver throttled through requestAnimationFrame re-injects the button, with a setInterval backstop. yt-navigate-finish resets the panel to its normal width.

Maximizing

Toggling adds .ytmax-panel--max, which switches the panel to position: fixed across the viewport. Its top edge is computed from the masthead's height and written to a --ytmax-top custom property, so the panel sits under the header rather than beneath it.

--ytmax-font: 18px;   /* YouTube's default is 14px */
line-height: 1.65;    /* headings scale to 1.25x */

Icons are pinned back to font-size: initial so they don't grow with the text.

Theming

YouTube's newer color-version theming resolves --yt-spec-text-primary to an empty string, so the button colour keys off the dark and darker-dark-theme attributes instead — the same signal the native close button follows. Verified: the button computes to rgb(241, 241, 241) in dark mode, matching close exactly.

Privacy

The extension requests no permissions, so there is no capability to misuse.

  • No network requests of any kind.
  • No storage permission; nothing is persisted.
  • No analytics, telemetry or tracking.
  • No remote code — everything ships in the package.
  • Cannot read any site other than YouTube, nor history or cookies.

Limitations
  • Targets YouTube's internal DOM, which YouTube changes without notice. A layout revision can break the button until the selectors are updated.
  • Desktop YouTube only; the mobile match pattern is included but untested.
  • The maximized state is deliberately not persisted — every page load starts normal.
  • Installed unpacked, so Chrome shows a developer-mode notice on each launch until it's on the Web Store.
